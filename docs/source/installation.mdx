# Installation

This guide uses `uv` as the default environment manager for faster and cleaner dependency isolation. If you prefer conda, see [Conda fallback](#conda-fallback).

## Optional: Configure proxy

If your network needs an HTTP proxy for package/model downloads, export it before installation:

```bash
export http_proxy=http://192.168.32.28:18000
export https_proxy=http://192.168.32.28:18000
```

## Step 1: Install `uv`

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
```

## Step 2: Create Python 3.10 environment (uv)

```bash
uv python install 3.10
uv venv --python 3.10 .venv
source .venv/bin/activate
```

## Step 3: Install ffmpeg

Install ffmpeg in your system environment:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg
```

> [!TIP]
> If your ffmpeg build does not support `libsvtav1` (check with `ffmpeg -encoders`), you can:
>
> - _[On any platform]_ install ffmpeg `7.X` from conda-forge:
>
> ```bash
> conda install ffmpeg=7.1.1 -c conda-forge
> ```
>
> - _[On Linux only]_ build ffmpeg from source with `libsvtav1` support:
>   [Dependencies](https://trac.ffmpeg.org/wiki/CompilationGuide/Ubuntu#GettheDependencies),
>   [Build instructions](https://trac.ffmpeg.org/wiki/CompilationGuide/Ubuntu#libsvtav1).

## Step 4: Install LeRobot from source 🤗

### From Source

First, clone the repository and navigate into the directory:

```bash
git clone https://github.com/huggingface/lerobot.git
cd lerobot
```

Then install dependencies. For PI/PI0.5 training, install with the `pi` extra:

```bash
python -m pip install -U pip setuptools wheel
python -m pip install -e ".[pi]"
```

## Step 5: Verify installation

Run the checks below to confirm you are using the intended environment and that PI0.5-specific transformer patches are available:

```bash
which python
python -V
which pip
python -c "import transformers; print('transformers:', transformers.__version__)"
python -c "from transformers.models.siglip import check; print('siglip patch ok:', check.check_whether_transformers_replace_is_installed_correctly())"
```

For PI0.5, `siglip patch ok` should print `True`.

## Conda fallback

If you prefer conda/miniforge, use:

```bash
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
conda create -y -n lerobot python=3.10
conda activate lerobot
conda install -y ffmpeg=7.1.1 -c conda-forge
python -m pip install -U pip setuptools wheel
python -m pip install -e ".[pi]"
```

### Installation from PyPI

**Core Library:**
Install the base package with:

```bash
python -m pip install lerobot
```

_This installs only the default dependencies._

**Extra Features:**
To install additional functionality, use one of the following:

```bash
python -m pip install 'lerobot[all]'          # All available features
python -m pip install 'lerobot[aloha,pusht]'  # Specific features (Aloha & Pusht)
python -m pip install 'lerobot[feetech]'      # Feetech motor support
```

_Replace `[...]` with your desired features._

**Available Tags:**
For a full list of optional dependencies, see:
https://pypi.org/project/lerobot/

> [!NOTE]
> For lerobot 0.4.0, if you want to install pi, you will have to do: `python -m pip install "lerobot[pi]@git+https://github.com/huggingface/lerobot.git"`

### Troubleshooting

If you encounter build errors, you may need to install additional dependencies: `cmake`, `build-essential`, and `ffmpeg libs`.
To install these for linux run:

```bash
sudo apt-get install cmake build-essential python3-dev pkg-config libavformat-dev libavcodec-dev libavdevice-dev libavutil-dev libswscale-dev libswresample-dev libavfilter-dev
```

For other systems, see: [Compiling PyAV](https://pyav.org/docs/develop/overview/installation.html#bring-your-own-ffmpeg)

## Optional dependencies

LeRobot provides optional extras for specific functionalities. Multiple extras can be combined (e.g., `.[aloha,feetech]`). For all available extras, refer to `pyproject.toml`.

### Simulations

Install environment packages: `aloha` ([gym-aloha](https://github.com/huggingface/gym-aloha)), or `pusht` ([gym-pusht](https://github.com/huggingface/gym-pusht))
Example:

```bash
python -m pip install -e ".[aloha]" # or "[pusht]" for example
```

### Motor Control

For Koch v1.1 install the Dynamixel SDK, for SO100/SO101/Moss install the Feetech SDK.

```bash
python -m pip install -e ".[feetech]" # or "[dynamixel]" for example
```

### Experiment Tracking

To use [Weights and Biases](https://docs.wandb.ai/quickstart) for experiment tracking, log in with

```bash
wandb login
```
